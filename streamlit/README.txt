
Streamlit demo app for Gym Heart-Attack Risk (beginner-friendly)
Files created:
- /mnt/data/streamlit_app/app.py
- /mnt/data/streamlit_app/sample_input.csv
- /mnt/data/streamlit_app/requirements.txt

How to run locally:
1. Create a virtualenv and activate it
2. pip install -r requirements.txt
3. streamlit run app.py (run this inside /mnt/data/streamlit_app)

The app runs on http://localhost:8501 by default.
